═══════════════════════════════════════════════════════════════════
   🎓 ADMIN QUESTION BANK VIEWER - QUICK REFERENCE
═══════════════════════════════════════════════════════════════════

📍 LOCATION: Admin Panel → Tests → View Teacher Questions

🎯 PURPOSE: View and review ALL test questions created by teachers

═══════════════════════════════════════════════════════════════════
   ⚡ QUICK START
═══════════════════════════════════════════════════════════════════

1. Login as Admin
2. Sidebar → Tests → "View Teacher Questions"
3. Use filters to find specific tests
4. Click "View Questions" to see full test
5. Review questions, answers, and marks

═══════════════════════════════════════════════════════════════════
   🔍 FILTERING OPTIONS
═══════════════════════════════════════════════════════════════════

Filter By:
   👤 Teacher       → See specific teacher's tests
   📚 Subject       → Filter by subject
   🎓 Year Group    → Filter by class level
   ⏱️ Status        → Not Started / In Progress / Completed
   🔎 Search        → Search test names

💡 TIP: Combine filters for precise results!
Example: Teacher=Mr. Smith + Subject=Mathematics + Year=SS2

═══════════════════════════════════════════════════════════════════
   📊 STATISTICS DASHBOARD
═══════════════════════════════════════════════════════════════════

Top Cards Show:
   📄 Total Tests      → All tests in system
   👥 Total Teachers   → Teachers who created tests  
   📚 Total Subjects   → Subjects with tests

═══════════════════════════════════════════════════════════════════
   📋 TESTS TABLE FEATURES
═══════════════════════════════════════════════════════════════════

✅ Sortable Columns  → Click headers to sort
✅ Pagination        → 25 tests per page
✅ Export Options    → Excel, PDF, CSV, Print
✅ Built-in Search   → DataTable search box
✅ Color-Coded       → Status badges (Yellow/Green/Gray)

═══════════════════════════════════════════════════════════════════
   👁️ VIEWING QUESTIONS
═══════════════════════════════════════════════════════════════════

When you click "View Questions":

TEST SUMMARY:
   • Total Questions
   • Total Marks
   • Average per Question
   • Test Duration

EACH QUESTION SHOWS:
   • Question text
   • 4 options (A, B, C, D)
   • ✓ Correct answer (highlighted green)
   • Marks allocated
   • Solution/explanation (if available)

═══════════════════════════════════════════════════════════════════
   🎨 STATUS INDICATORS
═══════════════════════════════════════════════════════════════════

Badge Colors:
   🟡 Yellow = Not Started
   🟢 Green = In Progress
   ⚫ Gray   = Completed

Correct Answer:
   ✓ Green badge with checkmark

═══════════════════════════════════════════════════════════════════
   ✅ WHAT YOU CAN DO
═══════════════════════════════════════════════════════════════════

✓ View all teachers' tests
✓ See all questions and answers
✓ Filter by teacher/subject/year
✓ Export to Excel/PDF/CSV
✓ Monitor question quality
✓ Review marks allocation

═══════════════════════════════════════════════════════════════════
   ❌ WHAT YOU CANNOT DO
═══════════════════════════════════════════════════════════════════

✗ Edit questions (read-only)
✗ Delete questions
✗ Create new tests
✗ Modify test settings

WHY? This is an OVERSIGHT tool, not an editing tool.
Teachers manage their own questions via Staff Panel.

═══════════════════════════════════════════════════════════════════

Problem: No tests showing
Solution: Click "Reset Filters" | Check if teachers created tests

Problem: Questions don't load
Solution: Table might not exist | Contact tech support

Problem: Strange characters in questions
Solution: Encoding issue | Usually still readable

Problem: Export not working
Solution: Check internet connection | Try different format
