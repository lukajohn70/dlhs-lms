═══════════════════════════════════════════════════════════════════
   🚀 COMMON TASKS - HOW TO:
═══════════════════════════════════════════════════════════════════

📤 UPLOAD A FILE:
   1. Click "Upload New File" (top right)
   2. Drag & drop files OR click upload area
   3. Fill required fields: Category, Subject, Title
   4. Set target audience (All/Specific Class/Students)
   5. Check "This is an assignment" if applicable
   6. Add due date and max marks for assignments
   7. Click "Upload Files"

🔍 FIND A SPECIFIC FILE:
   Method 1: Use search box - type filename/title
   Method 2: Combine filters - select category + subject
   Method 3: Sort table - click column headers

🗑️ DELETE MULTIPLE FILES:
   1. Check boxes next to files you want to delete
   2. Click "Delete Selected" button
   3. Confirm deletion
   4. Done! Files removed instantly

👁️ PREVIEW A FILE:
   1. Find file in list
   2. Click eye icon (👁️)
   3. Modal opens with preview
   4. Download if preview not available

📊 SWITCH TO TABLE VIEW:
   1. Click "Table" button above file list
   2. Now you can sort by clicking column headers
   3. Use pagination at bottom (10/25/50 per page)
   4. DataTable search works too

📝 GRADE A SUBMISSION:
   1. Scroll to "Pending Submissions" section
   2. Click "Grade" button on a submission
   3. Review student's work in modal
   4. Enter grade (validated against max marks)
   5. Add feedback (optional but recommended)
   6. Click "Submit Grade"

═══════════════════════════════════════════════════════════════════
   ❓ TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════

Problem: "No files showing"
Solution: Click "Reset" filters, or refresh page

Problem: "Upload fails"
Solution: Check file size < 50MB, file type allowed

Problem: "Can't delete file"
Solution: Ensure you own the file (you uploaded it)

Problem: "Preview not working"
Solution: Some file types don't preview - download instead

Problem: "Grading button missing"
Solution: Only assignments you created show grading option
